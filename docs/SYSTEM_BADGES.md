# Original System Recognition Badges

Last reviewed: 2026-08-03

These badges are original, unofficial navigation marks for L2PTTRPG. They are designed to communicate each game's genre or core play identity without copying publisher logos, protected artwork, signature typography, or trade dress.

## Approved visual directions

| System | Badge direction | Recognition goal |
|---|---|---|
| D&D Fifth Edition — 2014 | Clearly faceted d20 with a visible `20` | Immediately reads as classic d20 fantasy |
| D&D Fifth Edition — 2024 | Clearly faceted d20 with a visible `20` and a separate revision spark | Reads as D&D-style d20 play while remaining distinguishable from the 2014 card |
| Pathfinder Second Edition Remaster | Hexagonal tactical badge with a large, legible `3A` | Communicates Pathfinder's three-action economy |
| Call of Cthulhu Seventh Edition | Original winged/tentacled eldritch head | Communicates cosmic investigative horror without using Chaosium marks |
| Daggerheart | Original heart, blade, circle, and diamond duality mark | Communicates heart, danger, Hope, and Fear |
| Vampire: The Masquerade Fifth Edition | Original twin-fang shield with a blood drop | Communicates gothic vampire horror without using World of Darkness marks |

## Non-negotiable boundaries

- Do not use official game or publisher logos unless a specific license is deliberately adopted and followed.
- Do not trace, closely imitate, or recolor official marks.
- Do not use a publisher's signature font, layout, border system, or trade dress to make a badge appear official.
- Keep the game name and edition visible beside the badge; icons never carry the full identification burden.
- Treat the badges as decorative in accessibility markup because the adjacent text supplies the accessible name.

## Review checklist

Before approving a badge change:

1. Render the full badge set at card size and guide-header size.
2. Confirm the intended concept is recognizable without reading the internal icon ID.
3. Check contrast on the actual site backgrounds.
4. Check mobile scaling and reduced-motion behavior.
5. Compare against official publisher marks for accidental similarity.
6. Run the badge regression tests.
7. Update `PROJECT_STATUS.md` and the relevant GitHub issue.
